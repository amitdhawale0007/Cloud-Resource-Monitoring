ARCHITECTURE & ENGINEERING BRIEF

Cloud Resource Monitoring Dashboard

A lightweight, framework-free cloud operations dashboard built with pure HTML5, CSS3, Vanilla JavaScript, and Chart.js. Engineered to run seamlessly offline or in any modern browser without external servers or cloud accounts.

Current Engine

Version 1: Local Simulation Engine

Version 1 runs completely client-side in your web browser. No cloud bill, no API keys, and no backend dependencies are required.

Client Browser (HTML5 / CSS3 / Vanilla JS)
↓ Requests state update
MockCloudService (Random-walk simulator with bounded metrics)
↓ Dispatches data points
UI Manager & Chart.js Render Engine
  • Zero Cost: No paid cloud subscriptions needed.
  • Instant Setup: Open index.html in any browser.
  • Deterministic Testing: Easily simulate CPU spikes (>90%) to test alerting pipelines.
Future Roadmap

Version 2: AWS CloudWatch Integration

The code structure features an abstract CloudDataProvider pattern. To switch to live AWS production monitoring, replace the simulation adapter with a real backend proxy.

Dashboard Frontend (Vanilla JS)
↓ REST API / WebSocket (JWT Bearer Auth)
Python FastAPI / Flask Backend (Hosted on EC2 or AWS Lambda)
↓ AWS IAM Role (Boto3 SDK)
Amazon CloudWatch Metrics & EC2 Telemetry
  • Security: AWS IAM credentials never touch the browser.
  • Least Privilege: Backend uses read-only cloudwatch:GetMetricData policies.
  • Caching: Backend caches metrics in Redis to minimize AWS API costs.

Backend Integration Guide: Python FastAPI + AWS Boto3

How to bridge this dashboard to real Amazon EC2 & CloudWatch instances securely

# backend_service.py - Secure CloudWatch Proxy (Python 3.11 + FastAPI + Boto3)
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
import boto3
from datetime import datetime, timedelta, timezone

app = FastAPI(title="CloudWatch Pulse Proxy API")

# Enable CORS for local development dashboard
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000", "http://127.0.0.1:5500"],
    allow_credentials=True,
    allow_methods=["GET"],
    allow_headers=["*"],
)

# Connect Boto3 using IAM Instance Profile or environment variables
# DO NOT hardcode AWS access keys or secrets in source code!
cloudwatch = boto3.client('cloudwatch', region_name='us-east-1')
ec2 = boto3.client('ec2', region_name='us-east-1')

@app.get("/api/v1/metrics/cpu")
async def get_instance_cpu(instance_id: str = "i-0a89f3b1e84"):
    """Fetch live CPU Utilization from Amazon CloudWatch."""
    end_time = datetime.now(timezone.utc)
    start_time = end_time - timedelta(minutes=15)
    
    response = cloudwatch.get_metric_data(
        MetricDataQueries=[{
            'Id': 'cpu_util',
            'MetricStat': {
                'Metric': {
                    'Namespace': 'AWS/EC2',
                    'MetricName': 'CPUUtilization',
                    'Dimensions': [{'Name': 'InstanceId', 'Value': instance_id}]
                },
                'Period': 60,
                'Stat': 'Average'
            },
            'ReturnData': True
        }],
        StartTime=start_time,
        EndTime=end_time
    )
    return response['MetricDataResults']
